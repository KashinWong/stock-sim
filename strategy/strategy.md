# 选股策略（agent 自迭代）

> 本文件是 agent 的策略大脑。每个交易日收盘后由 agent 复盘当日盘中交易并修改，每处改动须记录【理由 + 证据】。

## 当前策略版本：v3.0（多因子分层漏斗选股 · 盘中实时交易）

最后更新：2026-06-11

> **选股升级**：从「6 板块内挑技术形态」升级为全市场多因子分层漏斗
> （L0 动态候选池 → L1 基本面硬过滤 → L2 多因子打分，见下「一」节）。
> 运行模式不变：盘中每 5 分钟轮询实时交易，风控（止盈止损/急跌/仓位/尾盘）全部保留。
> 成交价 = 轮询那一刻 `quote.py realtime` 最新价立即成交（不模拟盘口/滑点）。

### 一、选股信号体系（v3.0 多因子分层漏斗）

选股逻辑由 `scripts/screen.py` 执行，因子参数在 `strategy/factors.json`（机器可读，复盘时改）。
分三层漏斗：
- **L0 动态候选池**：全市场按（涨幅+量比+换手）强势扫描取 Top100，打破板块锁死。
- **L1 基本面硬过滤（一票否决）**：剔除 ROE<0 / 净利为负 / PE_TTM>150 或为负 / ST。
- **L2 多因子打分**：技术(趋势+动量) + 资金(龙虎榜净买+北向持股) + 横截面相对强弱 + 估值（反向），
  各因子 z-score 标准化后按 factors.json 权重加权，输出 Top-N 候选。

当前权重（factors.json v3.0）：trend 0.20 / momentum 0.15 / lhb_netbuy 0.15 /
northbound 0.10 / rel_strength 0.25 / valuation 0.15。

agent 巡盘时跑 `python scripts/screen.py rank --top 10` 取候选，再用 `quote.py daily` 复核趋势，
**仍须过下方「二、买入规则」的开仓铁门槛**才下单。
focus_sectors 不再用于盘中盲扫，仅用于 prepare 板块缓存与复盘归因。

### 二、买入规则

- **开仓铁门槛（v2.1 强化·先于一切信号判断）**：任何开新仓/加仓，**买入当时最新价必须 ≥ 当时 MA20 且 MA20 方向向上**。
  日线方向层不过（现价跌破 MA20，或 MA20 走平/向下）的票**一律不开仓**，无论分时涨幅多强、无论"分散主线"理由多充分。
  分散度是开仓的「加分项」，绝不能成为绕过日线方向层的「免检理由」。
- **允许盘中开全新仓**（不限于已选候选池，可基于盘中涨幅榜临时纳入），但须先过上一条铁门槛。
- 单只买入金额不超过总资产的 **30%**。
- **单一主线/板块（PCB+半导体算同一科技硬件主线）持仓合计 ≤ 总资产 40%**。
  欲突破 40% 须先分散到 **≥2 条相关性较低的主线**（科技硬件 / 电力 / 新能源 不算同一线）。
- **单一主线满仓前置门槛**：仅当持仓已覆盖 ≥2 条主线时，总仓位方可超过 60%；否则总仓位上限锁 60%。
- 买入数量向下取整到 100 股整数倍。
- 同一标的当日盘中加仓不超过 **3 次**（盘中节奏放宽，但仍防无限磨损手续费）。
- **硬约束（account.py 已强制，下单前 agent 也要自查）**：现价有效（非停牌/0 价）、
  未触及涨跌停区间外（主板 ±10% / 双创 ±20% / ST ±5%）。触限的单 account.py 会直接拒，
  agent 不要反复重试同一笔废单。

### 三、卖出规则

- **止盈**：浮盈达 +20% 减半仓；+35% 清仓。
- **止损**：浮亏达 **-10%** 无条件清仓。
- **盘中急跌止损（v2.0 新增）**：单笔持仓在 30 分钟内回撤 >6%（从当日盘中高点算）→ 减半仓避险。
- 跌破 20 日均线清仓。
- **T+1 约束**：当日买入次日才可卖（account.py 已强制，agent 不要试图当日卖出当日买入仓）。

### 四、仓位管理

- 最大持仓数：5 只。
- 单主线持仓上限 40% 总资产（见买入规则）。
- 现金保留：至少保留总资产 **15%** 现金。
- **尾盘纪律（14:50 后）**：14:50 之后不再开新仓，只做止盈/止损/减仓的防守性操作，避免隔夜裸奔新仓。
